# Security Policy

This project is a prototype and is not intended to guarantee continuous or
unattended operation.

Do not report exploitable vulnerabilities publicly. Use GitHub's private
vulnerability reporting for this repository when available. Otherwise contact
the repository maintainer privately through GitHub.

Do not include Wi-Fi passwords, receiver tokens, MQTT credentials, recordings,
or other private data in an issue or pull request. Keep local configuration in
the ignored `include/secrets.h` file.
